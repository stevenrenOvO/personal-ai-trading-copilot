## 1. V1.0 已实现的功能与完整数据链路

### 1.1 产品定位

本地运行的个人 A 股**超短线交易决策与审计系统**：每天打开即可回答「市场能不能做 → 情绪阶段 → 最强板块 → 连板梯队 → 有限个值得关注的机会 → 风险与仓位 → 模拟交易 → 决策记录 → 审计」，所有结论可展开看到依据，系统不编造行情与交易数据。

### 1.2 完整链路

```
数据层    HistoryProvider(SQLite 全市场日线) + QuoteService(30 秒快照) + auto_ingest(收盘自动补数)
  ↓
Step 1    当日数据服务：双级缓存(内存+SQLite)、后台刷新、as_of / age_seconds / is_stale / 交易阶段
Step 2    梯队引擎：首板 / 二板 / 三板 / 四板及以上、断层、炸板、回封、
          昨日涨停溢价与晋级率（按昨日高度拆分）、行业梯队与角色（龙头/中军/补涨候选）
Step 3    情绪周期：6 阶段规则表（冰点 / 修复 / 发酵 / 高潮 / 分化 / 退潮）
          + 命中规则 + 每项证据(值/阈值/是否命中) + 阶段切换条件 + 强度构成
Step 4    机会链路：候选池（热点板块 × 连板梯队 × 个股角色）
          → 四层硬淘汰（标的层 / 板块层 / 梯队层 / 结构层，一票否决）
          → 七类机会独立判定（首板 / 连板接力 / 打板 / 弱转强 / 分歧转一致 / 半路 / 低吸）
          → 买点状态机（观察 → 触发中 → 可执行 → 失效）
          → 可拆解排序（环境 20 + 板块 25 + 梯队 20 + 个股 20 + 买点 15 − 风险扣分 30）
          → A/B/C 分层（A 级为阶段限额而非分数线）+ 建议仓位 + why_not_buy
          → 事件研究 / 对照组 / 稳健性验证工具
  ↓
交易与复盘 模拟盘（持久化，T+1 / 100 股整手 / 涨跌停不可成交 / 一字板不可买）
          + 决策日志 + 交易审计 + 个人画像
AI       工具化取数（市场 / 情绪 / 板块 / 机会 / 持仓 / 风控 / 策略 / 交易 / 审计 / 画像）
```

### 1.3 页面（8 个标签）

| 页面 | 已实现内容 |
|---|---|
| 总览 | 今天能不能做、情绪周期、建议仓位、最强板块、值得关注的机会（A 级优先）、涨停环境评级 |
| 市场 | 涨跌/涨停/跌停/炸板/封板率/最高连板/成交额/三大指数均值 + 「情绪周期判定（为什么是当前阶段）」 |
| 机会 | Step 4 全链路展示：候选 → 类型 → 状态 → A/B/C → 排序分拆解 → 仓位 → why_not_buy；C 级折叠 |
| 涨停环境 | 梯队结构、各高度明细、昨日涨停今日表现、行业梯队与结构角色 |
| 复盘/审计 | 模拟交易表单、决策记录表单、账户快照、交易记录（卡片）、交易审计、个人画像 |
| 回测 / AI 助手 / 策略健康 | 辅助功能，不喧宾夺主 |

### 1.4 自动化能力

- **盘中**：快照后台每 30 秒刷新（免费源为延迟快照，非实时盘口）。
- **收盘后**：`auto_ingest` 自动补齐**所有缺失交易日**（自愈式，回溯上限 10 个交易日，从旧到新），并清理派生缓存；
  另有后台循环每 300 秒自查一次，**不依赖是否有人打开页面**。
- 触发条件：交易日收盘后（阶段为「收盘 / 盘后」）且当日无日线数据；非本地历史库、盘中阶段均为空操作；供应商失败不影响服务。

## 3. 验收结果：测试 / API / 无未来函数 / 交易规则

### 3.1 pytest

```
238 passed, 2 skipped in 9.51s
```

- 2 个 skip 为需要真实 Token / `RUN_LIVE_DATA_TESTS=1` 的联网测试。
- 覆盖范围：数据层、市场、情绪（规则表含边界与矛盾场景）、板块、梯队、机会类型与状态机、排序与风控、回测、模拟盘、决策日志、审计、画像、AI、API、前端契约。

### 3.2 API

- **20 个正式接口全部返回 200**：
  `/health`、`/market/state`、`/emotion/state`、`/sectors`、`/board/environment`、`/board/ladder`、
  `/opportunities`、`/opportunities/candidates`、`/opportunities/setups`、`/opportunities/plan`、
  `/risk`、`/positions`、`/strategies`、`/strategies/health`、`/trades`、`/profile`、
  `/backtest/runs`、`/data/latest`、`/data/history/dates`、`/ai/copilot`
- 早期骨架的 4 条 `/api/*` fixture 路由（`/api/backtest`、`/api/paper/snapshot`、`/api/profile`、`/api/opportunity/scan`）**已下线**，现返回 404，并有契约测试防止其回归（同时确认前端不再引用）。

### 3.3 无未来函数 / 数据泄漏

- 全库扫描无负向 `shift(-)`；引擎仅使用 **T 日及以前**数据，执行恒在 **T+1**。
- 回测引擎自带 `_detect_lookahead` 并在结果中返回 `lookahead_issues`。
- 分歧转一致类型将「T+1 一致性确认」标记为 `verifiable=False, passed=None`，不使用未来数据反推 T 日信号。
- 事件研究执行口径：**T+1 开盘买入（仅当开盘价低于涨停价）→ T+2 开盘卖出**（T+1 制度不允许当日卖出）。

### 3.4 A 股交易规则

| 规则 | 实现 | 验证 |
|---|---|---|
| T+1 | 模拟盘与回测均禁止当日卖出；验证工具按 T+1 买、T+2 卖 | 测试覆盖 |
| 100 股整手 | 仓位换算向下取整到整手 | 测试覆盖 |
| 涨停不可买入 | 涨停价不假设成交，T+1 开盘即在涨停价视为未成交 | 测试覆盖 |
| 一字板不可成交 | 一字板不计入可执行 | 测试覆盖 |
| 跌停不可卖出 | 回测/模拟盘遵守 | 测试覆盖 |
| 资金不足 | 明确提示「无法按当前建议仓位建立最小仓位」，不给出虚假股数 | 测试覆盖 |
| 手续费/印花税/滑点 | 回测引擎内建 | 测试覆盖 |

### 3.5 复盘链路一致性

- 模拟盘持仓**持久化**（`data/paper/state.json`），服务重启后现金/持仓/订单保持。
- 模拟盘成交、决策记录共用同一份决策日志；审计基于真实记录生成（错误类型 / 严重度 / 证据 / 建议）。
- 个人画像在样本不足时明确显示「样本不足」，不生成虚构统计。
- 已清除历史 smoke test 假交易（归档为 `data/journal/trades.smoke-test-backup.jsonl`），画像从干净状态开始。

稳健性：

- 剔除最好的 5%（219 笔）后：均值 **−1.34%**、胜率 38.5%。
- 前半段（2,199 笔）：胜率 41.7%、均值 −0.73%；后半段：胜率 41.3%、均值 −0.40%；`halves_consistent = true`（两段同号为负）。

**必须记录的三条结论：**

1. **当前日线信号未跑赢对照**：A 层 −0.05% vs 对照组 −0.13%，差距在噪声范围内（A 层仅 114 笔可成交样本），不构成统计优势；**B 层 −0.58% 明确跑输对照组**。
2. **强市信号买不到**：高潮阶段 74 个信号 **100% 未成交**（T+1 全部涨停开盘，按"不在涨停价买入"的诚实假设）。**越强的信号越不可执行**，这本身是一种选择性偏差，必须让使用者知道。
3. **仅「修复」阶段为正**（+0.88%，272 笔，胜率 55.9%）；分化（−0.96%）与高位接力（−2.48%）最差。

样本与可验证性：日线可验证（首板/接力次日表现、晋级率、板块效应、分层有效性）；**必须分钟数据**（半路买点、是否开板、回封时点、09:35 开盘强弱）；**当前无法回测**（竞价强弱、封单量、精确涨停时间、打板可成交性）。

## 6. 已知限制与 V1.1 候选清单

### 6.1 未接入（页面与接口均标注，未伪装）

- 分钟数据、集合竞价过程、封单量、精确涨停时间 → 半路与日内打板在 V1.0 **不可执行**
- 概念/题材板块（仅行业分类，跨行业题材会漏）
- 退市/历史股票名单 → **存在幸存者偏差**，回测结论需谨慎
- 流通市值 / 换手率 / 量比（`daily_basic`）→ 流动性硬淘汰未启用，只标注「流动性未验证」
- 成交额（腾讯补齐日缺失 9.03%）
- Tushare 未接入（免费源已满足日线需求；有 Token 时可切换）

### 6.2 口径与设计上的已知限制

- 不复权价 vs 软件默认前复权显示（做涨停/结构判定必须用原始价）
- 涨停家数排除次新与除权股；连板高度按本地交易日序列，**停牌会中断连板**
- 情绪阶段存在 **1 日滞后**（日线结构收盘才成立）；当日行情未落地时自动回退到最近确认交易日并明确标注
- 打板在当前数据下只能是「收盘确认 / 次日开盘计划」，不假设涨停价成交
- 策略健康度不自动更新；模拟盘无成交历史查询页
- 自动更新依赖电脑开机且服务在运行

### 6.3 V1.1 候选（按优先级，均未开始）

1. **成交额源升级**（BaoStock/东财为主 + 腾讯兜底）→ 消除 9.03% 缺失、启用流动性硬淘汰、让成交额进入情绪规则
2. 当日 ST 名单、`daily_basic`（流通市值/换手/量比）
3. 概念题材板块（修正「行业 ≠ 题材」）
4. 候选股分钟数据（开盘强弱 / 是否开板 / 回封时点）→ 半路与日内打板才真正可执行
5. 退市名单（修正幸存者偏差）
6. 策略健康度自动更新、模拟盘成交历史页
7. 定时任务（电脑关机也能更新数据）

## 7. V1.0 冻结声明

自本报告生成起，**V1.0 冻结**：

1. **不再新增功能**。
2. **不调整策略规则、阈值、权重与排序逻辑**。

4. 冻结范围内的改动仅限：Bug 修复、明确标注、以及本报告的维护。
5. 第 6.3 节的候选项全部属于 V1.1，需另行确认后再开发。
