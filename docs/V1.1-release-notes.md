## 已完成的修复与优化

| 范围 | 交付行为 |
|---|---|
| 账户与成交 | 零值不会替换成默认资金；手工单要求正价格、正整数股数及整手买入；共享涨跌停、停牌限制；按批次执行 T+1，今日加仓不锁住旧仓 |
| 账户可靠性 | 原子保存、写失败回滚；本机多进程共享文件锁，事务前重读状态；重复订单核对原请求；损坏或丢失的已有账户停止交易 |
| 日志与画像 | 成交事件随账户持久化，日志可幂等恢复；冲突不覆盖原日志，显示待恢复；按有结果的平仓记录统计，计入完整费用与持有期 |
| 决策记录 | 独立保存所选日期和数量；request_id 防止超时重试重复记录，同 ID 不同内容返回冲突；失败重试 ID 可跨页面刷新保留 |
| 估值、计划与 AI | 使用共享账户；有效行情估值并标记日期和成本回退；非法/未来报价不覆盖有效历史价；净值峰值持久化；缓存读取最新账户版本 |
| 数据与补数 | 生产不使用测试样例兜底；保存真实报价日期；按覆盖率补数，失败持久化，5 分钟起指数退避至 6 小时；多个缺失日期合并个股下载，逐日核验 |
| 行情时效 | 上午快照不会随时间自动变成收盘数据；失败后持续标记过期；页面读取不能打断行情退避；跨日缓存明确显示所选日期未确认 |
| 回测与研究 | 收盘确认保护退出后等待次日开盘，遵守跌停限制；统一批次、加仓成本、买卖费用；无成交量不成交；拒绝无效/重复/矛盾日线；交易胜率与上涨日占比分开 |
| 滚动测试 | 拒绝非法窗口；测试前用历史预热，每折从独立现金账户开始；胜率按平仓笔数汇总；首日成本计入收益与回撤 |
| 回测记录 | 完整结果原子保存到本地，重启后可读取，网页返回最近 50 次记录；同一时刻只运行一个回测，避免重复请求争用计算资源 |
| 网页体验 | 防止旧日期请求覆盖新结果；全失败、部分失败和审计未完成分别提示；审计最多 4 并发；表单防双击；空数据不显示默认评分/仓位；无样本显示样本不足 |
| 启动与状态 | 一键启动/停止、进程身份核对、日志归档；首页/健康检查独立于数据源；新增账户、日历、历史、行情、补数状态；适配窄屏 |

原审查 B01–B16 中可由当前代码修正的问题均已处理。B10 涉及的真实历史证券状态仍需外部数据，见后文。

## 打开与验收

1. 双击根目录 `start.cmd`，访问 <http://127.0.0.1:8000/>。
2. 发布名统一后，`/health` 的 version 应为 `1.1`。`/ready` 区分启动中、账户故障与部分数据待完善；这条版本展示说明不改写当时的验证结果。
3. 展开顶部运行状态，查看行情日期、历史覆盖和补数情况；后台状态每 30 秒更新。
4. 选择已落地日期，检查市场、机会、涨停环境与 AI 的日期依据；切换日期后最终结果应对应新选择。
5. 查看复盘页：账户不随历史日期回放；无平仓样本显示“样本不足”；模拟单与决策记录有各自的数量和日期。
6. 缩窄浏览器检查导航、状态卡、表单；回测运行时按钮等待，失败时给出提示。

日线策略在当日结构未确认时显示等待确认；最新交易日是否完整以运行状态为准。后台仍持续补数据，已有历史日期可用于检查研究与复盘。

更新代码后先运行 `stop.cmd` 再启动。停止脚本只停止身份验证匹配的本项目进程；旧手动启动的无记录进程需按原启动方式停止。

## 数据与能力边界

- 真实历史 ST、上市/退市、复权和公司行动数据不完整；当前股票名单存在幸存者偏差。只使用截至 T 日数据的启发式无法替代真实证券状态，研究报告已标明。
- 行情与日线依赖外部接口，缺口保留真实缺失并重试；长期联网表现受供应商影响。分钟、竞价、封单、盘口与历史行业排名需要新数据接入。
- AI 提供结构化查询和简报；开放式 LLM 后端尚未接入，配置 Key 不会被报告为已可用。
- 文件账本支持同本机遵守 sidecar 锁的多进程；网络盘或外部工具绕过锁修改文件不在支持范围。模拟 API 使用当前交易日，历史重放使用独立回测账户。
- 费用、滑点和成交条件是冻结的研究假设。当前两策略在固定样本与滚动测试中均表现不足，后续应补数据并做独立样本验证。

上述边界已反映到页面和报告；后续新增数据或 LLM 能力时需要相应验收。

## 升级与恢复

优化前原账户如存在，备份位于 `data/tmp/v1_1-backup-*`。旧 buy_date 持仓可迁移为一个结算批次；新格式含 requests、buy_lots、trade_records、peak_equity 和 version，不应由旧服务覆盖。

成交事件保存在账户文件，`trades.jsonl` 是可恢复的日志投影。日志暂时无法写入或内容冲突时，账户保留成交并提示待恢复；先修复日志，再由后续请求或重启重放。坏账户不会静默恢复成默认百万现金。
