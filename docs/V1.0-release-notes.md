# Personal AI Trading Copilot — V1.0 Release Notes

Tag: `v1.0.0` ｜ 状态：**最终冻结**（不再新增功能、不调整策略/阈值/权重/排序/数据口径）

## 这是什么

本地运行的个人 A 股**超短线交易决策与审计系统**：数据 → 市场状态 → 情绪周期 → 板块强度 → 连板梯队 → 候选池与硬淘汰 → 七类机会与买点状态机 → 可拆解排序 → 风控与仓位 → 模拟交易 → 决策日志 → 交易审计 → 个人画像 → AI 解释。

打开 `http://127.0.0.1:8000/` 即可使用；手机同 Wi-Fi 用 `--host 0.0.0.0` 启动后访问电脑内网 IP（响应式布局，核心页面可用）。

## V1.0 包含

- 全市场日线本地库（SQLite）+ 当日延迟快照（30 秒后台刷新，带 `as_of / age / is_stale`）
- 收盘后**自动补齐缺失交易日**（自愈式 + 后台循环，无需每天手动跑命令）
- 情绪周期六阶段规则判定（可解释：命中规则 + 每项证据 + 切换条件）
- 连板梯队（首板/二板/三板/四板+/断层/炸板/回封/昨日涨停溢价/晋级率）与行业梯队角色
- 机会链路：候选池 → 四层硬淘汰 → 七类机会 → 状态机（观察/触发中/可执行/失效）→ A/B/C 分层 → 建议仓位 → `why_not_buy`
- 模拟盘（T+1 / 100 股整手 / 涨跌停不可成交 / 一字板不可买 / 持久化）、决策日志、交易审计、个人画像
- 事件研究 / 对照组 / 稳健性验证工具

## ⚠️ 策略验证结果：**当前信号不代表盈利优势**

全历史事件研究（20260601–20260917，78 个交易日，T+1 开盘买入、T+2 开盘卖出、涨停不可成交）：

| 分组 | 成交样本 | 胜率 | 平均收益 |
|---|---|---|---|
| A 层 | 114 | 45.6% | **−0.05%** |
| B 层 | 4,285 | 41.4% | **−0.58%** |
| 对照组（同区间非候选股票） | 22,796 | 44.7% | −0.13% |

- **A 层与对照组基本持平**（−0.05% vs −0.13%，差距在噪声范围内，A 层样本仅 114 笔，不构成统计优势）。
- **B 层明确跑输对照组**（−0.58% vs −0.13%）。
- 仅「修复」阶段为正（+0.88%，272 笔）；分化 −0.96%；**高潮阶段 74 个信号 0 个可成交**（T+1 全部涨停开盘，按诚实假设视为买不到）。
- 剔除最好 5% 交易后均值 −1.34%，前后半段同为负。

**结论：V1.0 的价值在于「决策流程、数据可追溯与审计」，不在于已被证明的收益能力。请勿据此直接实盘。**

## 已知限制

**未接入**（页面与接口均明确标注，未用其它指标伪装）：

- 分钟数据、集合竞价过程、封单量、精确涨停时间 → 半路与日内打板在 V1.0 不可执行
- 概念/题材板块（仅行业分类）
- 退市与历史股票名单
- 流通市值 / 换手率 / 量比
- 成交额在腾讯补齐日缺失（9.03%）

**生存偏差**：股票池仅含当前上市股票，**未包含已退市股票，回测结论存在幸存者偏差**，需谨慎解读。

**其它**：情绪阶段有 1 日滞后（日线结构收盘才成立）；不复权价与软件默认前复权显示不同；打板只能作为"收盘确认 / 次日开盘计划"，不假设涨停价成交；自动更新依赖电脑开机且服务运行。

## 数据源与同花顺的口径差异（**合理差异，不做强行对齐**）

| 差异项 | 分类 | 说明 |
|---|---|---|
| 回补日无成交额 | 数据源差异 | 腾讯日线接口不提供 turnover，未估算 |
| 涨跌停价 | 统计口径差异 | 本地按 `pre_close × 板块规则` 推导，非交易所公布字段 |
| ST 名称与 5% 限制 | 数据源差异 | 名称快照会过期，已按个股近期波动校正 |
| 除权/送转日涨跌幅 | 复权差异 | 全为不复权价 |
| 停牌 / 涨停家数 / 连板高度 | 统计口径差异 | 停牌日无 bar；本地方排除次新与除权股；停牌中断连板 |
| 概念题材板块 | 统计口径差异 | 仅行业分类，跨行业题材会漏 |
| 盘中时间戳 | 时间差异 | 只有延迟快照，无逐笔/竞价时间 |

数据一致性审计（411,245 行 / 5,222 代码）：OHLC 非法 0、重复主键 0、涨跌幅偏差 0、**我方 Bug 无**。
