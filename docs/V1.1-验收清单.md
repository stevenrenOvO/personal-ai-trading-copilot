## 请用户检查

- [ ] 打开网页后，顶部版本显示 v1.1，展开状态可看到行情日期、历史覆盖及后台补数。
- [ ] 选择一个已有历史交易日，依次查看总览、市场、机会、涨停环境、AI；切换后内容对应所选日期。
- [ ] 选择当前未确认的交易日，应显示等待确认，不展示默认评分、仓位建议或跨日数据正常。
- [ ] 复盘页账户、样本数和持仓正常；模拟单与决策记录的日期、数量互不影响。
- [ ] 运行一次指定区间的回测，完成后刷新或重启服务，记录仍存在。
- [ ] 缩窄窗口或用手机检查导航、表单和状态卡。服务默认仅本机可访问；同 Wi-Fi 真机访问需按 README 使用指定 host 启动。
- [ ] 阅读研究报告中的负收益结果与数据限制，确认本版研究口径。

若后台仍在补数据，运行状态显示“部分数据待完善”属于真实数据状态；历史日期可以先验收。请记录出现问题的页面、所选交易日和提示文字，以便复查。
