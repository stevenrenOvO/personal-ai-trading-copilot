# V1.1 发布说明

日期：2026-10-24。统一发布版本为 `1.1`，Git标签为 `v1.1`，包含开发期间的数据、交易与页面修复及本轮收尾。发布信息和下载附件以[V1.1官方发布页](https://github.com/stevenrenOvO/personal-ai-trading-copilot/releases/tag/v1.1)为准。

## 本轮优化

- 已成交订单可跨日期、重启和日历故障恢复；同一ID更换原始交易条件会被拒绝，不会产生第二次成交。
- AI结构化查询实际展示结果，并与机会页共享Step4计划、进攻判断、仓位上限和基准日期；旧扫描不再作为主机会来源。
- 涨停环境复用已确认的结构情绪，避免与总览同日不同阶段；市场参考仓位与实际机会计划上限分开标明。
- 就绪状态区分关键缺口与覆盖充分后的少量缺失，显示指数是否同日更新；界面使用“可分析/覆盖率”说明门槛，不宣称所有证券数据完整。
- 行情快照不可用但已有当日日线时仍能展示；不再每5秒重复扫描未变化的历史库；日期选择不会触发无边界网络历史查询。
- 新增安装脚本、锁定35个运行依赖，移除运行清单中未使用的数据库/模型依赖；测试依赖独立。
- 离线演示固定样例日期、禁止接入实时源，使用独立账户目录和8001端口；真实模式保持8000端口。
- 启动后恢复调用终端的环境变量，同一终端先启动演示再启动真实模式也不会误用演示目录；原有自定义数据路径得到保留。
- 真实数据支持只初始化证券名单/日历，再由后台补日线；空历史库与完整证券目录可恢复填充。
- 发布包采用源码白名单、逐文件清单和SHA256，排除真实data、.env、账户、日志、缓存和进程记录；解包验证禁止联网。

## 安装、升级与发布范围

解压后双击setup.cmd；先用start-demo.cmd检查页面，再按README初始化真实数据并运行start.cmd。运行/开发依赖分开，源码中的前端交互测试需要Node，日常运行不需要。

升级前停止服务并备份原.env与data。将新版解压到独立目录，完成安装，再拷贝需要沿用的配置和数据；保留原目录及升级前数据作为回退依据。不要用旧程序覆盖新版账户文件。

本次交付是Windows个人本地工具的源码包，验证环境为Windows 64位Python 3.13，覆盖本机页面、窄屏浏览器、模拟盘及离线演示；手机真机和其他操作系统未据此宣称完成验证。真实行情库、账户和研究冻结原始数据不随包分发。历史ST/退市/复权/分钟等限制以及开放式LLM缺失仍明确保留；旧研究报告是2026-10-22冻结的开发期基线，不能充当本版新的盈利验证。研究报告中的软件版本展示随发布命名统一为 `1.1`；实验没有重算，指标、样本、实验指纹和归档哈希保持原样。
