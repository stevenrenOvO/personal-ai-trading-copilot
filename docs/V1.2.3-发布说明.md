# V1.2.3 发布说明

发布版本 `1.2.3`。这是使用期内的界面修复版本。起因是第一次试用的反馈：「太复杂、数据太多、不知道自己在干嘛、抓不到重点」。规则、计算和数据格式都没有改，可以直接覆盖升级。

## 1. 导航分成两组
- 顶部导航：**今日 · 我的股票 · 计划 ｜ 市场 · 机会 · 涨停 · 复盘 ｜ 更多**。左边一组管每天的操作，中间一组是全市场短线研究，都直接显示在顶部。
- 「更多」里只放不常用的页面：设置、总览、回测、AI 助手、策略健康。
- 「今日」「我的股票」「计划」页面不再显示服务状态和交易日选择。手机上导航自动换成两行，不需要横向滑动。

## 2. 「今日」先给一句话结论
- 顶部大字直接写「**要做 N 件事**」或「**不用操作**」，下面一行说明哪天执行（例如「11-25 周二 · 开盘前设好就行，不用盯盘」），再一行说明市场情况（例如「市场偏弱，最多用 2,400 元（20%），还能用 1,170 元」）。
- 每件事一张卡片，**一句话说怎么做**，例如：
  - 「开盘后卖掉全部 100 股」
  - 「挂限价 1,486.85 元，买 100 股」，下方小字「开盘高于 1,486.85 就不买 · 买到后止损设 1,385.61」
  - 「止损单设在 18.82」
- 右上角一个状态词：**该卖了 / 可以买 / 留意 / 计划 / 提醒**。
- 金叉、量比、21 日线、离场规则这些依据，都收进「为什么 ▸」，需要时再点开。
- 大字下面是「**今天的盘面**」三格：**市场**（例如「亢奋 · 涨 4,294 / 跌 780」）、**涨停**（「151 家 · 高潮 · 最高 5 板」）、**机会**（「A 级 3 只 · 可进攻，最多新开 1 只」）。点任意一格进入对应页面。这部分是全市场短线视角，和你自己的波段规则分开显示；某天的数据还没准备好时显示「待确认」，不会拿别的日期的数据凑数。
- 不需要操作的持仓合并成一行「其余 N 只持有中，止损单都已设好」，点开能看到每只的止损线。
- 按钮用大白话：已买入 / 不买了 / 已卖出 / 暂不卖 / 已设止损 / 能买吗？
- **第一次使用**（还没有股票时）会显示 3 步引导：添加股票 → 标记持有 → 每天收盘后看「要做几件事」。

## 3. 「我的股票」每只股票一个状态词
- 分成「**持有中**」和「**观察中**」两组。每行只显示股票名、一个关键事实和一个状态词：
  - 持有中：**该卖了 / 留意 / 安全 / 看不清**，例如「赚 6.4% · 离止损还有 10%」「已在止损线下方」；
  - 观察中：**可以买 / 快了 / 等待 / 看不清**，例如「买入信号出现了」「快到买点了」「趋势不对，先不看」。
- 点一行展开详细内容：成本、股数、止损线，「我持有 / 我卖了 / 能买吗？/ 移除」按钮，以及详细依据。
- 添加股票的输入框放在列表底部，直接输入名称。
- 原来的「交易前检查」改名为「**能买吗？**」，收进这一页，可以展开使用。

## 4. 试用中发现的问题
- **当天买入的股票显示「看不清」**：所有规则都按最近一个收盘判断，系统发现买入日期比最新数据还晚，就放弃了判断。现在当天买入的股票按「刚买入」处理：止损线用上一个收盘的 21 日线计算（实测：宁波东力 18.82、慈文传媒 8.59），盈利 15% 后改用回撤止损的规则要等买入后第一个收盘再开始计算。如果买入前股价已经有效跌破 21 日线，会明确提示「按你的规则这笔不该买」。
- **当天买入时显示了误导性的盈亏**：原来拿成本和**昨天**的收盘价比较，显示「亏 14.7%」。现在显示「今天刚买」，第一个收盘之后再显示盈亏。
- **涨停环境页「昨日涨停溢价」没有四舍五入**：原来显示 7.427313333333333，现在显示 7.43%。
